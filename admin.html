NAGA ROOM 物件管理

Firestore に物件を登録します。初回は下のセットアップから始めてください。

初回セットアップ（ローカル）

Firebase Console で次の3つを済ませてから、下のフォームに Web アプリの設定を貼ってください。

  1. Firebase Console → あなたのプロジェクト → 構築 → Firestore Database → データベースを作成（リージョンは asia-northeast1 推奨）
  2. Firestore → ルール → 下のルール全文をコピーして貼り付け → 公開
  3. プロジェクトの設定（歯車）→ 全般 → 「アプリを追加」→ Web → 表示された firebaseConfig の値を下に入力（または JSON を一括貼り付け）

JSON を貼ったあと「フォームに反映」を押すと、下の各項目に入ります。
